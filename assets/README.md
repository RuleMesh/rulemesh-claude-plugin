# Marketplace assets

Listing icon (the blue mesh mark, no wordmark), sourced from the brand repo `Design/assets`:

- `icon.svg` — vector mark, preferred for the Connectors Directory
- `icon.png` — 256×256
- `icon-512.png` — 512×512

Requirements for the Anthropic Connectors Directory and the plugin listing:

- Square, 256×256 minimum, transparent background, no text in the mark
- PNG and SVG; SVG preferred for the directory
- Blue-only logo per the RuleMesh logo guidelines (Deep Blue `#1e40af`, Light Blue `#60a5fa`, Bright Royal `#2563eb`). The logo is blue-only, full stop.
- Pink (`#E8398A`) is the problem-side accent and does not belong on the logo or any product surface.

Source the mark from the brand repo (`logo-guidelines.md`) rather than regenerating it.
